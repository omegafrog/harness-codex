# Harness 모델 색인

현행 모델은 [통합 DDD Architecture 계약](../contracts/architecture.md)이 소유한다. 기능·규칙은 [전체 Product 계약](../contracts/product.md), 시각적 탐색은 [클릭 가능한 DDD 보기](../contracts/architecture.html)를 사용한다. 이 파일에 책임/규칙의 사본을 유지하지 않는다.

`CONTEXT.md`는 유비쿼터스 언어, `CONTEXT-MAP.md`는 Context 색인이다. ticket별 Spec과 ADR은 결정·변경 이력이며 현재 구현 상태와 구분한다. 변경 시 `sync-contracts`로 현행 계약과 다이어그램을 갱신하고 완료 gate를 검증한다.
