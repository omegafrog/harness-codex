## 3. 시작 유스케이스
- 유스케이스: UC-003. End User Clears the Calculator State
- 액터: End user
- 목표: End user resets the current expression and current result.
- 초기 커맨드: 🟦 계산기 상태 초기화를 요청하라

### 사전 조건
- The calculator page loaded successfully.
- The current page session is active in a supported desktop browser.

### 종료 조건
- 성공: The current page session shows an empty in-memory calculator state.
- 실패: Clear 이후 현재 수식 또는 현재 결과가 남아 있으면 실패이다.

## 7. 규칙 (Invariant)
- Clear 이후 현재 페이지 세션의 수식 상태는 항상 empty여야 한다.
- Clear 이후 현재 페이지 세션의 결과 상태는 항상 empty여야 한다.
- Repeated Clear must preserve the same empty calculator state.
- Cleared state must remain in-memory only for the current page session.
