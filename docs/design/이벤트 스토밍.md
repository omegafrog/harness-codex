---

## 1. 시작 유스케이스

- 유스케이스: UC-01. 플레이어가 싱글 플레이 세션을 시작하거나 이어서 플레이한다
- 액터: 플레이어
- 목표: 새 게임을 시작하거나 기존 진행 상태를 불러와 핵심 플레이 루프를 이어간다.
- 초기 커맨드: 🟦 세션 시작 방식을 선택한다

### 사전 조건

- 게임 클라이언트가 PC 브라우저에서 실행 가능해야 한다.
- 기존 저장 데이터가 있을 수도 있고 없을 수도 있다.

### 종료 조건

- 성공: 플레이어는 유효한 싱글 플레이 세션 상태로 게임을 시작한다.
- 실패: 최신 저장 데이터와 직전 정상 저장 스냅샷을 모두 복구할 수 없으면 새 게임 시작만 제공한다.

---

## 2. 흐름

### [Flow: 기본 흐름]

🟦 세션 시작 방식을 선택한다
→ 🟧 게임 접속이 요청되었다
→ 🟪 로컬 저장 데이터 존재 여부를 확인하고 선택 가능한 시작 방식을 노출한다
→ 🟧 시작 가능 방식이 제시되었다
→ 🟦 새 게임 시작 또는 이어하기를 선택한다
→ 🟧 세션 시작 방식이 선택되었다
→ 🟪 선택된 방식에 맞는 세션 상태를 로드한다
→ 🟧 세션 상태가 로드되었다
→ 🟪 로드된 독점도, 재료, 판매 현황, 해금 던전 정보를 초기 화면에 구성한다
→ 🟧 플레이 가능 세션 상태가 표시되었다

---

### [Flow: 예외 흐름]

🟦 게임에 접속한다
→ 🟧 저장 데이터 조회가 요청되었다
→ 🟪 저장 데이터가 없으면 새 게임 시작만 제공한다
→ 🟧 새 게임 시작만 가능한 상태가 표시되었다

🟦 이어하기를 선택한다
→ 🟧 저장 데이터 복구가 시도되었다
→ 🟪 최신 저장 데이터가 손상되었으면 직전 정상 저장 스냅샷 복구를 시도한다
→ 🟧 직전 정상 저장 스냅샷 복구가 시도되었다
→ 🟪 직전 정상 저장 스냅샷도 복구할 수 없으면 새 게임 시작만 제공한다
→ 🟧 저장 데이터 복구 실패와 새 게임 시작 경로가 표시되었다

# UC-02. 플레이어가 던전 탐사를 준비하고 재료를 수집한다 이벤트 스토밍

---

## 1. 시작 유스케이스

- 유스케이스: UC-02. 플레이어가 던전 탐사를 준비하고 재료를 수집한다
- 액터: 플레이어
- 목표: 목표 시장을 뒤흔들 수 있는 새로운 재료를 확보하고, 어떤 특성의 도구가 유용한지 단서를 얻는다.
- 초기 커맨드: 🟦 던전 탐사를 준비한다

### 사전 조건

- 플레이어가 탐사 가능한 세션 상태여야 한다.
- 최소 1개 이상의 던전이 해금되어 있어야 한다.

### 종료 조건

- 성공: 플레이어는 제작 가능한 재료와 향후 아이템 설계에 필요한 단서를 확보한다.
- 실패: 탐사 준비 미완료 시 진입하지 못하고, 공략 실패 시 기본 보상의 50%만 획득하며 희귀 재료와 특성 단서는 획득하지 못한다.

---

## 2. 흐름

### [Flow: 기본 흐름]

🟦 던전 탐사를 준비한다
→ 🟧 던전 후보 확인이 요청되었다
→ 🟪 해금된 던전의 분위기, 위협, 기대 재료, 유용한 특성 단서를 제시한다
→ 🟧 탐사 준비 정보가 표시되었다
→ 🟦 모험가 동행 구성을 확정한다
→ 🟧 탐사 준비가 확정되었다
→ 🟪 준비가 완료되면 던전 진입을 허용한다
→ 🟧 던전 진입이 승인되었다
→ 🟦 던전에 진입한다
→ 🟧 던전 탐사가 수행되었다
→ 🟪 탐사 결과에 따라 재료 보상과 특성 단서를 생성한다
→ 🟧 재료가 획득되었고 단서가 제시되었다
→ 🟦 마을로 복귀한다
→ 🟧 탐사 결과가 세션에 반영되었다

---

### [Flow: 예외 흐름]

🟦 던전 진입을 시도한다
→ 🟧 탐사 준비 검증이 요청되었다
→ 🟪 탐사 준비가 완료되지 않았으면 진입을 막는다
→ 🟧 던전 진입이 거부되었다

🟦 던전 공략을 수행한다
→ 🟧 공략 실패가 발생하였다
→ 🟪 공략에 실패하면 기존 보유 재료는 유지하고 기본 보상 50%만 지급하며 희귀 재료와 특성 단서는 제외한다
→ 🟧 실패 결과가 반영되었다

- 유스케이스: UC-05. 플레이어가 창의적 쓰임을 이용해 시장 독점도를 높인다
- 액터: 플레이어
