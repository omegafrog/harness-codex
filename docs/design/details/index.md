## 5. 설계 규칙 요약
- 도메인 규칙 위치: 세션/인벤토리/가판대/시장상태 루트 메서드와 세션복구, 탐사결과생성, 제작속성계산, 창의적쓰임해석, 판매결과계산, 경쟁시장대응, 시장지배력갱신 도메인 서비스에 둔다.
- 상태 변경 경로: 유스케이스 -> 애플리케이션 서비스 -> Aggregate Root 메서드 -> 성공 후 자동 저장 순으로 제한한다.
- 외부 협력 처리: 브라우저 로컬 저장소와 디버그 로그는 포트로 분리하고, 다른 BC는 동일 프로세스 동기 클라이언트로 연계한다.
- BC 경계 보호: BC는 다른 BC 내부 엔티티를 직접 수정하지 않고 ID 또는 요약 DTO만 교환한다.

## 6. 확정 결정
- 자동 저장 스냅샷은 게임세션, 인벤토리, 가판대, 시장상태를 하나의 JSON 문서로 묶어 브라우저 로컬 저장소에 저장한다.
- BC 간 협력은 프로토타입에서 이벤트 버스 없이 동일 프로세스 동기 호출로 처리한다.
- 판매 완료된 제작품은 활성 인벤토리와 가판대 슬롯에서 제거하고 판매 이력 요약으로 보존한다.
