# LENS-DOMAIN 도메인 전문가

전문가 관점이다. 이해관계 당사자가 아니므로 원하는 것이 없고, 요청된 업무를 업무 지식으로 검토한다.

## 점검 순서

요청 문구 하나씩 아래를 따져 본다. 각 후보 요구사항은 그 문구를 `request_anchor`로 인용해야 한다.

1. 업무 목적: 이 문구가 누구에게 어떤 결과를 주는가.
2. 행위자와 권한: 누가 이 행위를 시작하고, 누가 할 수 없는가.
3. 정상 흐름: 시작부터 완료까지 업무 단계.
4. 업무 규칙: 항상 참이어야 하는 조건.
5. 예외: 흐름이 정상적으로 끝나지 않는 경우와 그때의 업무 결과.
6. 완료 조건: 업무가 끝났다고 말할 수 있는 관찰 가능한 상태.

요청 문구로 이어지지 않는 업무 지식은 앵커 없는 관찰(`request_anchor: null`)로만 낸다.
