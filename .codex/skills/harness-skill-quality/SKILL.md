# Skill Quality Check

1. Trigger: make the description precise and minimal.
2. Structure: keep procedure in `SKILL.md`; move conditional detail to one-level references.
3. Guidance: begin each step with the next action and preserve plan-mode decisions.
4. Prune: delete every sentence whose removal leaves the result unchanged.
