# Technical Decision Write Rules

쓰기 범위는 다음 중 선택된 문서 하나다.

- Feature: `docs/changes/active/<CHG-ID>/technical-decisions.md`
- Maintenance: `docs/maintenance/<MAINT-ID>/technical-decisions.md`

`template.md`를 따른다. 미해결 질문이 있으면 `status: needs_input`과 추천안을 기록한다. 모든 결정이 확정됐거나 `기술 문제 없음`일 때만 `status: ready`다.
